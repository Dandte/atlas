Empezar

De cero a ATLAS en 5 minutos

Clona, configura tu API key, y ATLAS cobra vida.

terminal
# Clonar el repositorio
git clone https://github.com/Dandte/atlas.git
cd atlas

# Instalar dependencias
npm install

# Configurar
cp .env.example .env
nano .env

# Compilar y lanzar
npm run build
npm run start

# 🚀 ATLAS está vivo
